# BaseRenchanRestfulApiLauncher

Extends `BaseRestfulApiLauncher` for Renchan backends. It adds no members of its own, and exists so that a Renchan launcher hierarchy has its own base class.

| member | description |
| :-- | :-- |
| `.create()` | Inherited factory method. |

Every member of [BaseRestfulApiLauncher](./BaseRestfulApiLauncher.md) is inherited.
