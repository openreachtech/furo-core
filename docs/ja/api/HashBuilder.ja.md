# HashBuilder

フラットな `a[b][c]` 形式のキーからネストしたハッシュを構築します。フォームのコントロール名が構造化された値ハッシュになる仕組みです。

| member | description |
| :-- | :-- |
| `.create()` | ファクトリメソッド。起点となる任意の `core` ハッシュを受け取ります。 |
| `#setValue()` | `name` のパスへ値を 1 つ代入します。ビルダー自身を返すため、メソッドチェーンが可能です。 |
| `#setValues()` | `[name, value]` の組の配列を代入します。ビルダー自身を返すため、メソッドチェーンが可能です。 |
| `#buildHash()` | 組み立てたハッシュを返します。ネストしたビルダーと末尾の `[]` キーを解決します。 |
