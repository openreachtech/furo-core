# DynamicDerivedCtorPool

派生コンストラクタを名前でキャッシュします。内部の `Map` は既定でモジュールスコープの共有インスタンスとなるため、キャッシュはプロセス内のすべてのプールインスタンスにまたがります。

| member | description |
| :-- | :-- |
| `.create()` | ファクトリメソッド。任意の `pool`（`Map`）を受け取ります。既定値はモジュールスコープの共有インスタンスです。 |
| `#registerCtor()` | コンストラクタを名前付きで登録します。既に保持している名前は変更されないため、最初の登録が優先されます。 |
| `#bulkRegisterCtors()` | 名前とコンストラクタのハッシュのすべてのエントリを登録します。 |
| `#retrieveCtor()` | 名前に対応するコンストラクタ。存在しない場合は `null`。 |
| `#containsCtor()` | 名前が既に保持されているかどうか。 |
