# BaseDatabase

IndexedDB のデータベースに名前を与え、そのマイグレーションを指し示します。データベースごとに継承し、各オブジェクトストアをゲッターとして公開します。

| member | description |
| :-- | :-- |
| `.create()` | ファクトリメソッド。既に開かれた `dbClient` を受け取ります。 |
| `.createAsync()` | データベースを先に開くファクトリメソッド。開く処理は非同期であるため、通常はこちらを使用します。 |
| `.get:dbName` | データベース名。オーバーライドが必須です。 |
| `.get:dbVersion` | データベースのバージョン。既定値は `1` です。マイグレーションを変更した際に上げてください。 |
| `.get:MigrationCtor` | マイグレーションクラス。オーバーライドが必須です。 |
| `.get:IndexedDbClientCtor` | データベースを開くために使用するクライアントクラス。 |
| `.get:config` | クライアントへ渡される名前とバージョン。 |
| `.createDbClient()` | データベースを開き、クライアントを返します。 |
| `.generateCallbacks()` | オープンリクエストのコールバック。以下の 3 つをまとめます。 |
| `.defineOnSuccess()` | データベースが開かれたときに呼ばれるハンドラー。 |
| `.defineOnError()` | オープンに失敗したときに呼ばれるハンドラー。 |
| `.defineOnUpgradeNeeded()` | バージョン変更時にマイグレーションを実行するハンドラー。 |
