# furo

`furo` はフロントエンド開発を支援するライブラリです。

純粋な JavaScript で書かれているため、Vue や React など、どのフロントエンドフレームワーク・ライブラリでも動作します。

## インストール

Node.js 20.x 以降が必要です。

```sh
npm install @openreachtech/furo
```

ES モジュール（`"type": "module"`）です。ESM の `import` 構文でインポートしてください。
